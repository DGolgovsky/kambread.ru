# АО «Камышинский хлебокомбинат» — Веб-портал (2026)

Официальный веб-портал и каталог продукции АО «Камышинский хлебокомбинат» (г. Камышин, Волгоградская область), перенесённый с устаревшего стека Yii2 / PHP 5.4 / jQuery 1.9 / Bootstrap 3 / Bower на современный стек по состоянию на ноябрь 2026 года.

## Стек технологий (ноябрь 2026)

- **Runtime**: Node.js 22 LTS, TypeScript 5.9
- **Frontend**: React 19, Vite 7, Tailwind CSS 4, React Router 7, Lucide React
- **Backend**: Express 5 (`server.ts`, порт `3000`, `0.0.0.0`) с REST API и сессионной авторизацией
- **Тестирование**: Встроенный `node:test` + `tsx`

## Функциональность

- **Главная страница**: витрина с интерактивным слайдером, преимущества предприятия (с 1956 года), избранная продукция, краткая история, лента новостей и торговые партнёры.
- **Каталог продукции (`/products`, `/products/:id`)**: поиск по названию и описанию, фильтрация по категориям (`Хлеб`, `Батоны`, `Булочки`, `Баранки`, `Кексы`, `Сухари`, `Эксклюзивная`), диапазону цен и признаку «Новинка», пагинация и форма отправки заявки в отдел маркетинга.
- **О компании (`/about`)**: история с декабря 1956 г., руководство, социальные гарантии, Камышинский арбузный фестиваль и архив наград.
- **Партнёрам (`/partners`)**: перечень документов для юридических лиц и ИП, условия сотрудничества.
- **Вакансии (`/vacancies`)**: открытые позиции с аккордеоном описаний и контактами отдела кадров.
- **Новости (`/news`, `/news/:id`)**: лента событий, фотогалерея и встроенные комментарии читателей.
- **Контакты (`/contact`)**: справочник отделов предприятия, валидируемая форма обратной связи и координаты площадки.
- **Личный кабинет (`/login`, `/cabinet`)**: управление каталогом продукции, новостями, вакансиями, наградами, входящими заявками и профилем (демо-доступ: `admin` / `admin2026`).

## Команды запуска

```bash
npm install
npm run dev      # Запуск сервера разработки на http://0.0.0.0:3000
npm run test     # Модульные тесты бизнес-логики
npm run build    # Проверка типов и продакшн-сборка
npm run start    # Запуск собранного приложения
```
